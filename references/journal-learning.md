# Research-aware journal and figure learning

Use this workflow when the task calls for research-informed or journal-specific adaptation. Ordinary recoloring, label edits and re-export do not require a literature search. Keep the study proportional; this is figure preparation, not an unsolicited systematic review or publication strategy project.

## 1. Extract research and evidence needs

Read available research descriptions, abstracts, methods, result tables, variable definitions and project configuration. Extract a compact task-local matrix:

| Dimension | Extract or infer with a label |
|---|---|
| Research object | Physical system or computational problem, domain and scale |
| Methods | Main algorithm/control/estimation/optimization terms; distinguish contribution from baseline |
| Claimed contribution | What the available evidence is meant to establish |
| Validation | Simulation, experiment, benchmark, case study, statistical ensemble |
| Metrics | Error, constraints, cost, robustness, runtime, uncertainty; units and domains |
| Figure types | Time history, trajectory, convergence, ablation, distribution, spectrum, heatmap |

Generate a few focused English keyword combinations and useful synonyms, retaining the original meaning. Separate supplied facts from inferred keywords. Search for papers whose figures answer a comparable question; vocabulary overlap alone is insufficient. Do not infer the intended venue from a local folder name.

Do not submit confidential manuscript text, private identifiers, unpublished numerical results or local paths to public search. Use generic research concepts and method names; if a distinctive unpublished term itself would reveal private content, generalize it or request authorization before external use.

## 2. Resolve the target

- Explicit journal: verify its exact identity and use it. Do not restart venue selection or substitute a more prestigious journal.
- No journal, but journal learning requested: suggest two or three candidates using official scope and recent thematically relevant research as evidence. Explain topical/evidence fit and uncertainty. Do not invent acceptance probabilities, rankings or impact factors. Obtain selection before applying a journal-specific profile, unless choosing the target was explicitly delegated.
- No journal-specific request: use the content-appropriate generic profile and proceed. Do not add a compulsory approval step.
- Multiple venues: keep separate profiles and identify the primary version; generate multiple export variants only if requested or necessary.

## 3. Retrieve a bounded reference set

Use official author/artwork guides for submission rules, and original publisher articles or legitimate author/repository versions for actual figures. Prefer connected sources or supplied accessible papers when available; use live web search for current requirements and missing examples. Preserve the user's requested search scope and budget.

Start with roughly three relevant original research articles and four to eight pertinent figures in total, commonly from the recent two to three years; these are sampling targets, not quotas or journal-wide evidence. Widen the date range only when topic coverage requires it and record why. Prefer a directly relevant older figure over an unrelated recent one.

Use at most two focused search/refinement rounds by default, then evaluate sufficiency. If coverage remains sparse, deliver a provisional profile and explicit limitations rather than searching indefinitely. Increase scope only for a concrete unresolved need within the task budget. Do not buy access, bypass access controls or install tools without authorization.

Verify title, publication year, journal and persistent URL/DOI where available. Identify final published, accepted manuscript or preprint status; preprint typesetting is not evidence of the final journal layout. Separate original research from reviews/editorial graphics. Do not count duplicate versions as independent examples.

## 4. Inspect actual figures

Render/open the relevant PDF pages or available full-resolution article figures. Read captions and surrounding definitions needed to understand the plot. Record article ID, figure number, panel/page and inspection extent. Abstract-only access may support topical relevance, never a visual-style observation.

For each figure, inspect:

- Scientific role and panel ordering: what comparison or evidence sequence the layout communicates.
- Axis pairing/scales/units, alignment, panel labels and comparable ranges.
- Font appearance, tick density, line/marker hierarchy, color accessibility, legend placement.
- Insets, transient versus steady-state views, constraint references and event markers.
- How individual replicates, central tendency, uncertainty, failure cases and ablations are presented.
- Readability at publication scale, not only at a large browser zoom.

Do not claim exact fonts, hex colors or point sizes from a screenshot. Mark visual estimates approximate; use PDF metadata or official guidance for values that can actually be verified. Do not confuse the publisher's article layout with the authors' plot style.

## 5. Synthesize evidence without overgeneralization

Use three clearly separated classes:

| Class | Meaning | Strength |
|---|---|---|
| Official requirement | Current author guide explicitly requires it | Binding for a compliance claim, subject to stage/article type |
| Observed convention | Seen in identified, actually inspected figures | Descriptive of that sample, not mandatory |
| Design decision | Adaptation chosen for the present evidence/data density | Justified locally; may depart from sampled practice |

Track contradictory examples and sample counts. One example is an example, not a consensus. A recurring convention should cite at least two independent articles; count only observations that were actually visible. Qualify coverage as sufficient for a provisional design or incomplete; avoid unsupported numerical confidence scores.

Partition learned choices by figure family. A spectrum, dense control response and statistical ablation need not share panel geometry. Adopt transferable information hierarchy and useful visual rules, not a distinctive complete composition. Do not reproduce others' data, captions or conclusions, and do not bundle article screenshots into the reusable skill.

## 6. Apply, inspect, finish

Save a concise study/profile using [task-profile.md](task-profile.md). Choose a base style and explain meaningful overrides. Preserve fixed method/component mappings across the result set.

Use one representative real-data figure for the first application check when results exist. Inspect at final size and compare with the evidence plan, then apply the coherent settings to the remainder. This check is normally agent-performed, not an extra user approval gate. Follow any explicit preview/approval request from the user.

Do not change metrics, scientific windows, sampling, normalization, successful/failed run inclusion or constraint thresholds to resemble the references. If a reference's summary plot would conceal the current dataset's limitations, choose a more honest layout and explain the departure.

When figures or guides are inaccessible, record precisely what was readable. Use available generic settings and label unverified elements; never claim visual inspection that did not occur. Deliver actual figures when authorized data and tools permit, not only a search summary or a style profile.

## 7. Reuse and privacy

Store keywords, candidate assessments, paper/figure notes, timestamps and profiles only in the current project. Reuse existing study records for the same target and figure family; revisit when the target, evidence needs or submission requirements change. Recheck official guidance for a new submission rather than assuming an old cached rule remains current.

Do not copy task research content, private paths or learned article-specific notes back into shared skill files or global defaults. A public/shareable report should omit confidential research details unless the user authorizes their inclusion. Public reference citations are appropriate in task-local research records.
