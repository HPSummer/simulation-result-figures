# Public design and API references

Reviewed 2026-11-13. These are references, not required dependencies. The helpers are original implementations; no repository source or private examples are bundled.

- SciencePlots: https://github.com/garrettj403/SciencePlots — inspiration for composable base/journal settings and restrained scientific line styles. Repository presets are not publisher guarantees.
- Scientific plotting conventions: https://github.com/jiutongzhao/scientific-plotting-conventions — reference for physical-size layout reasoning; not an authoritative journal policy source.
- Nature figure specifications: https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/ — editable graphics, accessible colors, typography; check current target guidance at submission.
- IEEE graphics: https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/ — technical export guidance.
- MATLAB exportgraphics: https://www.mathworks.com/help/matlab/ref/exportgraphics.html — vector export and explicit dimensions (dimension options since R2025a).
- Matplotlib rc_context: https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.rc_context.html — temporary styling without persistent global defaults.

If future edits copy third-party implementation/assets, first inspect the license and retain required attribution. A public source list never needs to identify a private user or manuscript.
